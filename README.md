# Words 1–6

Приложение для «4000 Essential English Words» (файл со словами и рассказами). В репозитории только код: книга и аудио остаются на устройстве.

## Как загрузить том (в Chrome на планшете)
1. Откройте приложение, вкладка **Книги**, выберите том.
2. **Выбрать PDF** → PDF тома (30 юнитов по 3 страницы).
3. **Выбрать mp3** → выделите сразу все файлы 01.mp3 … 60.mp3 (нечётные: слова, чётные: рассказы).
4. Журнал покажет, что найдено и какие фразы рассказа стоит проверить. Границы фразы можно поправить кнопкой ⏱ на вкладке «Аудио».

Данные лежат в памяти браузера (IndexedDB) и работают офлайн. Адрес приложения менять нельзя: данные привязаны к нему.

## Файлы (все в одной папке, без подпапок)
index.html, lib.js, store.js, ingest.js, units.js, tracks.js, sw.js, manifest.json, icon-192.png, icon-512.png,
pdf.min.js и pdf.worker.min.js (библиотека pdf.js, Apache-2.0, лицензия в pdfjs-LICENSE.txt).
